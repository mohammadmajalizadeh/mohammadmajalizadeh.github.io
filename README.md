# Mohammad Majalizadeh — Portfolio

Personal portfolio site, deployed at https://mohammadmajalizadeh.github.io/

## Updating the site

Edit the HTML/CSS/JS files, then commit and push:

```bash
git add .
git commit -m "Update site"
git push
```

GitHub Pages redeploys automatically within a minute or two.

## Adding projects

The admin panel is intentionally kept offline. On your own machine, open the
project folder and open `admin.html` in a browser (double-click it), fill in the
project form, then click **Export projects.json**.

Replace the `projects.json` file in this folder with the exported one, commit,
and push. Re-add `admin.html` to the site only if you ever want it online again.

## Files

- `index.html` — homepage
- `work.html` — Seamoon Shipping case study
- `about.html` — experience, skills, side quests, certifications
- `contact.html` — direct contact page
- `projects.json` — project data (kept for future use)
- `seamoon-hero.png`, `seamoon-live.png` — live screenshots
