# Mohammad Majalizadeh — Portfolio

Personal portfolio site, deployed at https://mohammadmajalizadeh.github.io/

## Updating the site

Edit the HTML/CSS/JS files, then commit and push:

```bash
git add .
git commit -m "Update site"
git push
```

GitHub Pages redeploys automatically within a minute or two.

## Adding projects

Open `admin.html` (while the site is open in a browser), fill in the project form,
then click **Export projects.json**. Replace the `projects.json` file in this
folder with the exported one, commit, and push. The "Project archive" section on
`work.html` renders whatever is in that file.

## Files

- `index.html` — homepage
- `work.html` — project archive and Seamoon Shipping case study
- `about.html` — experience, skills, side quests, certifications
- `contact.html` — direct contact page
- `admin.html` — project manager (not linked in the public navigation)
- `projects.json` — data for the project archive
- `seamoon-hero.png`, `seamoon-live.png` — live screenshots
